# みんなの動画（TeraBox版・自己責任）

TeraBoxの非公式API(`terabox-api`)を使い、TeraBoxの「openchat」フォルダの動画を一覧・再生・改名・削除します。
動画の保存場所はTeraBoxなので、Renderが再起動しても消えません。

## 重要な注意
- TeraBox公式のAPIではありません。仕様変更で突然動かなくなる、規約上の問題でアカウントに影響が出る可能性があります（自己責任）。
- ログイン情報(ndus)は必ず Render の環境変数にだけ入れ、GitHubには載せないでください。
- 動画はRenderを経由して配信されます。Render無料枠の通信量・速度の制限を受けます。

## 1. ndus の取り方（PCのブラウザ）
1. TeraBoxにログイン → F12 → Application(アプリケーション) → Cookies → terabox のドメイン
2. `ndus` の値をコピー（ログアウトや期限切れで無効になるので、動かなくなったら取り直す）

## 2. 手元で動作確認（先にこれを推奨）
1. TeraBoxアプリで `openchat` フォルダを作り、動画を1本入れる
2. `npm install` してから `TERABOX_NDUS=コピーした値 npm run check`
   「再生URL取得OK」「先頭100バイト取得: 206」と出れば成功

## 3. Renderにデプロイ
GitHubにpush → New → Blueprint。環境変数を設定:
MEMBER_PASSCODE / ADMIN_PASSWORD / TERABOX_NDUS（TERABOX_DIRは既定で /openchat）

## 使い方
- サイトの管理人用パネルから動画を選んでアップロードできます（TeraBoxアプリで上げた動画は「一覧を更新」で反映）
- アップロードは、ブラウザ → Render（一時保存）→ TeraBox の順で行います。1本あたりの上限は既定で1024MB（環境変数 MAX_UPLOAD_MB で変更。Render無料枠のディスク容量に注意）
- アップロード中はこのページを開いたままにしてください
- 動画の名前 = ファイル名。サイトの「名前を変更」でTeraBox上のファイル名も変わります

## 追加機能（v4）
- **眠り防止**: Renderが自分の `/healthz` に10分ごとにアクセスします（`RENDER_EXTERNAL_URL` はRenderが自動で設定）。
  念のため、UptimeRobot等の無料の監視サービスで `https://あなたのURL/healthz` を5〜10分おきに監視しておくと、再起動直後も早く復帰します。
  無料プランの月750時間は、このサービス1つを24時間動かすと使い切る計算です（他にRenderの無料サービスを動かすと足りなくなります）。
- **サムネイル**: 投稿時に画像を選ぶか、空なら動画の冒頭付近から自動作成。投稿後は「サムネ画像を選ぶ」「この場面をサムネに」で変更できます。サムネはTeraBoxの `openchat_thumbs` に保存されます。
- **管理人アカウント**: オーナー（`ADMIN_PASSWORD` でログインした人）が、画面から管理人のユーザー名・パスワードを作成。
  管理人は「管理人ログイン」から入り、動画を投稿でき、自分が投稿した動画だけ名前変更・サムネ変更・削除ができます。
  オーナーは全動画を編集でき、誰が投稿したかも見られます。アカウントの停止・パスワード変更・削除もオーナー画面から。
  アカウント情報は（パスワードはハッシュ化して）TeraBoxの `openchat_meta/meta.json` に保存されます。
- ログインは10分間に10回失敗すると一時的にロックされます。
